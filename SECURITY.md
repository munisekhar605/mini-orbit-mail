# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **Mini Orbit Mail**, please report it responsibly rather than opening a public issue.

- Contact maintainers directly via GitHub security advisories or by emailing: `munisekhar9056@gmail.com`
- Please provide details on how to reproduce the issue, potential impact, and suggested mitigation if known.
- We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a coordinated disclosure schedule.
